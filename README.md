# Nova Leads — рекламное агентство

Рекламное агентство, задача которого — рекламировать и приводить лиды
в разные бизнесы. Работаем по трём правилам: только факты из реальных
исследований, только правда (никаких выдуманных кейсов и цифр),
постоянное подтверждение компетенций.

## База знаний

- [docs/principles.md](docs/principles.md) — принципы работы агентства.
- [docs/benchmarks.md](docs/benchmarks.md) — отраслевые бенчмарки с
  первоисточниками (Google Ads, Meta, лендинги, speed-to-lead, email).
- [docs/competencies.md](docs/competencies.md) — карта компетенций и план
  самообучения с честными статусами.

## Что внутри

- `index.html` — одностраничный сайт: услуги, процесс работы, кейсы, тарифы,
  форма захвата лидов, контакты.
- `css/styles.css` — стили (тёмная тема, адаптивная вёрстка, без внешних зависимостей).
- `js/main.js` — мобильное меню, валидация и отправка формы заявки.

## Запуск

Статический сайт без сборки — достаточно открыть `index.html` в браузере
или поднять любой статический сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Подходит для публикации на GitHub Pages без дополнительной настройки.

## Приём заявок (лидов)

Форма на сайте валидирует имя и телефон и отправляет заявку:

- по умолчанию (для теста) заявки сохраняются в `localStorage` браузера
  под ключом `leads`;
- чтобы отправлять заявки в CRM или на бэкенд, укажите URL вебхука в
  константе `LEAD_ENDPOINT` в `js/main.js` — заявка уйдёт POST-запросом
  в формате JSON: `{ name, phone, email, niche, comment, createdAt }`.
