# Ассистент Дома — Maison Tina Riich

Ассистент Дома в мессенджерах. Две персоны, один код:

- **Рич** — соавтор Тины в личных чатах: разбор работ по канонам Дома, ведение долговременной памяти, задачи и напоминания.
- **Арина** — комьюнити-менеджер маркетинговых групп: отвечает участникам, держит тон Дома, сама поднимает разговор, когда чат затих.

Долговременная память живёт не в этом репозитории, а в **[AI-Creative-OS](https://github.com/tinaassistants1-jpg/AI-Creative-OS)** — ассистент читает `canon.md`, `journal.md`, `tasks.md` и дописывает в них через GitHub API. То, что зафиксировано в чате, остаётся в памяти Дома и после перезапуска.

## Статус каналов

| Канал | Личные чаты | Групповые чаты | Статус |
|---|---|---|---|
| Telegram | ✅ | ✅ | Работает |
| WhatsApp | — | — | Не реализован, см. [docs/WHATSAPP.md](docs/WHATSAPP.md) |

WhatsApp заложен в архитектуру: каналы скрыты за интерфейсом `ChannelAdapter`, и всё остальное — персоны, агент, инструменты, планировщик — от канала не зависит. Групповые чаты WhatsApp официальный Meta Cloud API не поддерживает, поэтому выбор бэкенда — отдельное решение с последствиями; разбор в `docs/WHATSAPP.md`.

## Что умеет

- **Отвечает как Рич или Арина** — характер и правила Дома в системном промпте, канон подтягивается из памяти.
- **Пишет в память Дома** — журнал (`journal.md`), идеи (`ideas.md`), каноны (`canon.md`), задачи (`tasks.md`). Каждая запись — коммит в AI-Creative-OS.
- **Ведёт задачи** — добавляет, показывает, закрывает пункты в `tasks.md`.
- **Напоминает** — разовые («напомни завтра в 10») и повторяющиеся («каждый понедельник»).
- **Разбирает изображения** — присланный кадр, мудборд или макет разбирается по канонам: композиция, свет, типографика, identity-lock, ownable-тест.
- **Поддерживает активность в группах** — если группа молчит больше 20 часов, Арина сама начинает разговор по рубрике дня. Если сказать нечего — молчит.

## Быстрый старт

```bash
git clone https://github.com/tinaassistants1-jpg/advertising_agency.git
cd advertising_agency
npm install
cp .env.example .env    # заполнить ANTHROPIC_API_KEY и TELEGRAM_BOT_TOKEN
npm run build
npm start
```

Пошагово, с получением токенов и настройкой группы, — в [docs/SETUP.md](docs/SETUP.md).

Через Docker:

```bash
cp .env.example .env    # заполнить
docker compose up -d
```

## Команды в чате

| Команда | Что делает |
|---|---|
| `/help` | Справка |
| `/status` | Настройки текущего чата |
| `/persona rich\|arina` | Сменить персону чата |
| `/community on\|off` | Арина сама поддерживает активность в группе |
| `/reset` | Забыть историю разговора (память Дома не трогает) |

Персона выбирается автоматически: личный чат → Рич, группа → Арина. `/persona` меняет это вручную.

## Когда ассистент отвечает

- **Личный чат** — на каждое сообщение.
- **Группа** — только когда обратились: по имени («Арина, ...»), через `@упоминание` или ответом на его сообщение. Остальные сообщения он читает и помнит, но молчит.
