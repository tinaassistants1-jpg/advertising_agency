## Правила ведения карты

- Статус «✅» ставится только когда в базе знаний есть данные с первоисточниками.
- Раз в квартал бенчмарки перепроверяются: отрасль меняется быстро, данные 2025
  года к 2027 могут устареть.
- Компетенция считается подтверждённой практикой только после реального
  проекта с измеренным результатом — база знаний это необходимый, но не
  достаточный уровень.
