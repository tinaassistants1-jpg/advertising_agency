   Дальше клиентами станут психологи-выпускники МИГ и бизнесы, пришедшие

   archive.org тоже вне allowlist. Досье клиента собрано из поисковой
   выдачи с пометкой «требует верификации».
6. **Сетевые настройки.** Владельцу дана инструкция добавить домены через

   всё ещё 403 — ожидаемо, политика применяется только к новым сессиям.

## Ключевые знания, добытые в сессии (детали в docs/benchmarks.md)

- Рынок: мировая реклама >$1 трлн в 2026 (dentsu), digital ~69% (WPP Media).
- Google Ads 2025 (LocaliQ/WordStream): CPC ~$5,26; CVR 8,18%.
- Meta 2025: CPL ~$27,66, разброс по отраслям $3–72.
- Лендинги (Unbounce): медианная конверсия ~6,6%.
- Speed-to-lead: ответ за 5 минут = ×21 к квалификации (MIT/InsideSales 2007);
  среднее время ответа компаний 42 часа, 23% не отвечают (HBR 2011).
- Email: ROI $36–42 на $1 (Litmus/DMA).
- Ниша МИГ: образование — одна из самых конверсионных ниш (Google CVR 11,4%,
  Meta CVR ~10%, CPL образование ~$21–77 в зависимости от канала).
- Mental health (будущие клиенты-психологи): конверсия-обращение ~$29 (США),
  минимальный осмысленный бюджет ~$300–400/мес, рамка CPA vs LTV.
- Пробел: публичных бенчмарков Яндекс Директ/VK по нише РФ нет — только
  тестовые кампании дадут реальные цифры.
- Находка по МИГ: в нише 4+ организации с похожими названиями (МИГиП, МГИ,
  МИГТиК, МИГАС) → риск размытия брендового трафика, нужна защита бренда.
