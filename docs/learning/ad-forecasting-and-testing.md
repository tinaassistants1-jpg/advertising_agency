# Прогнозирование, моделирование и тестирование рекламы

Методология агентства. Дата проверки источников: **2026-08-07**.

## 1. Прогнозная модель кампании (как считаем до запуска)

Воронка: Бюджет → Показы → Клики → Лиды → Дошедшие → Покупки.

Формулы:
- Показы = Бюджет / CPM × 1000
- CPL = CPM / (CTR × CR_лендинга × 1000) — либо берём CPL из бенчмарков
- Покупки = (Бюджет / CPL) × доходимость × конверсия_в_покупку
- CAC = Бюджет / Покупки; ROAS = Выручка / Бюджет

Правила честного прогноза:
1. Всегда три сценария (оптимист/база/пессимист) — диапазон, не точка.
2. Каждый входной параметр — из бенчмарка или собственных данных,
   с источником; допущения помечаются как допущения.
3. Прогноз обновляется реальными данными после первых 3–5 дней теста —
   модель живёт, а не пишется один раз.

## 2. Тестирование креативов и формулировок (Meta)

Источники: [учёт learning phase](https://adlibrary.com/posts/meta-ads-learning-phase-50-events-guide), [бюджет теста](https://roaspig.com/blog/minimum-viable-budget-testing-facebook-ads/), [значимость A/B](https://thread-transfer.com/blog/2025-08-03-meta-ads-ab-testing/).

Ключевая математика:
- **Learning phase Meta: ~50 конверсий/неделю на адсет.** Дневной бюджет
  для выхода = CPA × 50 / 7. При CPL 25 € это ~180 €/день — малые тесты
  из learning не выходят, и это нормально: цель малого теста — порядок
  величин, а не победа алгоритма.
- **Значимость по покупкам: 50–100 конверсий на вариант** — на малых
  бюджетах недостижимо. Поэтому:
- **Двухэтапный дизайн теста:**
  - Этап 1 — скрининг креативов по CTR (дёшево: чтобы отличить CTR 1,0%
    от 1,5%, нужно ~7 700 показов на вариант; α=0,05, мощность 0,8).
    Ищем явных лидеров и аутсайдеров, микроразличия не ловим.
  - Этап 2 — лучшие 2–3 креатива соревнуются по CPL; решение о
    масштабировании — по CPL и качеству лидов (доходимость), не по CTR.
- Одно изменение за раз: тестируем либо оффер, либо креатив, либо
  аудиторию. Порядок важности: оффер > креатив > аудитория > плейсменты.
- Минимум 7 дней на раунд; не трогать первые 3 дня.

## 3. Очеловечивание текстов (правило владельца, обязательное)

Все клиентские и рекламные тексты проходят два фильтра:

**Фильтр 1 — признаки «ИИ-следа»** ([источник](https://motionapp.com/library/frameworks/voice-copy-standards), [обзор](https://www.singlegrain.com/content-marketing-strategy-2/how-to-make-content-not-ai-generated-and-authentically-human/)):
- одинаковая длина предложений (у ИИ почти все 15–22 слова) → варьировать ритм;
- штампы-открывашки («в современном мире», «важно отметить») → убирать;
- хеджирование («может помочь», «потенциально») → конкретика;
- обобщения («специалисты», «профессионалы») вместо «вы» → обращаться к читателю;
- слишком гладкая структура «тезис-развитие-вывод» в каждом абзаце → ломать;
- тест «прочитай вслух»: спотыкаешься или звучит как пресс-релиз → переписать.

**Фильтр 2 — журналист.** Каждый текст перед публикацией вычитывает
редактор-журналист (отдельный агент с ролью журналиста): проверка на
ИИ-след, читаемость вслух, сохранность фактов. Правки фактов запрещены —
только стиль. Это обязательный шаг процесса, не опция.

## 4. Ограничения малых тестов (проговариваем клиенту заранее)

1. Тест на 1 000 € даёт: порядок CPL, сравнение гео, явных лидеров
   среди креативов, первые данные о качестве лидов. Не даёт:
   статистически чистого победителя по покупкам, стабильного CAC.
2. 1–3 покупки в тесте — это сигнал, а не статистика. Решение о
   масштабировании принимаем по совокупности: CPL + доходимость +
   качество разговоров менеджера с лидами.
3. Все цифры прогноза — гипотезы до первого контакта с рынком.
