# Реклама в РФ: правовые требования и пороги входа в каналы

Дата проверки источников: **2026-08-05**. Критично для клиента МИГ.

## 1. Маркировка интернет-рекламы (обязательна для всех)

Источники: [обзор требований ОРД/ЕРИР](https://cleverdata.ru/blog/statii/markirovka-internet-reklamy-erir-ord-erid), [инструкция по маркировке](https://soldimarketing.ru/zametki/syurprizy-markirovki-reklamy/).

- Вся интернет-реклама на аудиторию РФ маркируется: до запуска через
  **ОРД** (оператора рекламных данных) получается токен **erid**,
  данные уходят в **ЕРИР** (реестр Роскомнадзора).
- Отчётность в ЕРИР — не позднее 30 дней после запуска (акты, статистика).
- **Штрафы за нарушение:** ИП/должностные лица 100–200 тыс. ₽,
  юрлица 200–500 тыс. ₽.
- Практика: Яндекс Директ и VK Реклама маркируют креативы через собственных
  ОРД автоматически, но рекламодатель обязан передать свои данные
  (юрлицо/ИП, ИНН, договор). Посевы в Telegram-каналах маркируются вручную —
  зона риска.

**Вывод для агентства:** перед запуском для МИГ нужно юрлицо/ИНН
рекламодателя и договор — без этого маркировка невозможна.

## 2. Реклама образовательных услуг: лицензия

Источник: [запрещённые тематики Директа](https://blog.cybermarketing.ru/chto-zapreshheno-reklamirovat-v-yandeks-direkte/), [страница Яндекса про образование](https://direct.yandex.ru/ads/industry/obrazovanie).

- Если деятельность лицензируемая, а лицензии нет — рекламировать нельзя;
  Яндекс запрашивает документы по лицензируемым тематикам.
- Из более раннего поиска (hot-head.ru): короткие курсы, тренинги и программы
  личного развития **без лицензируемой образовательной деятельности** можно
  рекламировать без лицензии.
- **Честно: границу для случая МИГ я пока не знаю.** Дополнительное
  профессиональное образование с выдачей документов обычно требует лицензию;
  статус программ МИГ (документы об образовании? юрисдикция юрлица?) —
  открытый вопрос клиенту. До ответа не запускать рекламу с формулировками
  об «образовании/дипломах».

## 3. Доступность каналов для аудитории РФ

- **Meta (Facebook/Instagram) недоступна для таргетинга на РФ** (компания
  запрещена в РФ); Google Ads на РФ также не работает. Для российской
  аудитории — Яндекс Директ, VK Реклама, Telegram Ads, посевы.
- **Для русскоязычных в Европе** (сегмент МИГ: Сербия, Португалия) —
  Meta и Google доступны, работают бенчмарки из docs/benchmarks.md.

## 4. Пороги входа и стоимость каналов

Источники: [eLama про Telegram Ads](https://elama.ru/blog/zapuskaem-reklamu-v-telegram-kak-nastroit-kampaniyu-na-oficialnoy-platforme-messendzhera/), [условия eLama](https://elama.ru/blog/idealnye-usloviya-v-telegram-ads-na-ves-2025-god-komissiya-15-i-oplata-po-faktu-trat/), [гайд ppc.world](https://ppc.world/articles/prodvizhenie-v-telegram-cherez-direkt-i-telegram-ads-v-2025-polnyy-gayd-po-instrumentam-i-upravleniyu-byudzhetom/).

| Канал | Порог входа | Заметки |
|---|---|---|
| Яндекс Директ | низкий (тысячи ₽) | Основной канал горячего спроса в РФ |
| VK Реклама | низкий | Таргетинг по интересам/сообществам |
| Telegram Ads напрямую (реселлер) | от €500 + комиссия 20–30% + НДС 20% (≈€720–780) | Дорогой вход |
| Telegram Ads через eLama | старт от 0 €, оплата по факту, комиссия 10–20% | Минимальный CPM 0,7 € |
| Посевы в Telegram-каналах | от цены поста | Ручная маркировка erid — делать аккуратно |

## Что осталось изучить (честно)

- Точные правила Яндекса/VK для категории «образование» (какие документы
  запрашивают на практике) — проверится при первом запуске.
- Правила рекламы психологических услуг (для будущих клиентов-психологов).
- Детали отчётности ЕРИР при работе через агентский кабинет.
