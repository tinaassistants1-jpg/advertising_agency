# Пошаговая инструкция: запуск кампании M1 «ДОД 25.08» в Meta

Для исполнителя с доступом к кабинету клиента. Время выполнения ~1,5 часа
(без ожидания модерации). Вопросы — владельцу агентства.

## Шаг 0. Предусловия (проверить до начала)

- [ ] Доступ «Рекламодатель» к Ad Account МИГ в Business Manager.
- [ ] FB-страница и IG-аккаунт МИГ привязаны к BM (реклама идёт от них).
- [ ] Pixel ID получен; пиксель установлен на лендинге ppk.mig.institute
  (проверка: расширение Meta Pixel Helper — события PageView при заходе,
  Lead при отправке формы).
- [ ] Лендинг открывается по HTTPS, форма отправляет заявку в Google Sheets.
- [ ] Креативы утверждены (8 макетов из ТЗ дизайнеру), тексты — из этого
  документа.
- [ ] Способ оплаты в кабинете активен.

## Шаг 1. Кампания

Ads Manager → Create → цель **Leads** (Лиды) →
- Название: `PPK_DOD_2508_test`
- Buying type: Auction. Advantage campaign budget: **выключить**
  (бюджеты зададим на уровне групп).
- Категория объявлений: не относится к специальным категориям
  (образование не входит в special ads categories).

## Шаг 2. Группы объявлений (2 шт.)

**Общие настройки для обеих:**
- Conversion location: Website; Pixel: пиксель МИГ; событие: **Lead**.
- Даты: старт немедленно, стоп 24.08 включительно.
- Плейсменты: Advantage+ (автоматические).
- Возраст 27–55, все полы. **Язык: русский** (Detailed targeting →
  Languages → Russian).
- Интересы (Detailed targeting): Psychology, Psychotherapy, Gestalt
  therapy, Mental health + должность/образование не сужать (аудитория
  и так узкая).

**Группа 1 `DE-IL_practitioners`:** гео Германия + Израиль.
Дневной бюджет **15 €**.

**Группа 2 `Balkans_practitioners`:** гео Сербия, Черногория, Хорватия.
Дневной бюджет **10 €**.

(Итого ~25 €/день × 10 дней ≈ 250 €.)

## Шаг 4. Публикация и модерация

- Publish → дождаться модерации (обычно 1–24 ч). Если объявление
  отклонено — НЕ пересоздавать многократно (риск блокировки), написать
  владельцу агентства: скорректируем формулировку.

## Шаг 5. Мониторинг (правила первых дней)

- День 1–3: ничего не выключать (обучение алгоритма), только смотреть.
- День 3: выключить объявления с CTR < 0,5% ИЛИ CPL > 40 € при ≥ 500
  показов. Оставить минимум 2 объявления на группу.
- День 5: если у одной группы CPL стабильно вдвое ниже — перекинуть на
  неё 5 €/день с другой.
- Ежедневно сверять число лидов в Ads Manager и в Google Sheets
  (расхождение >20% — сигнал о проблеме пикселя, писать владельцу).
- Стоп всей кампании: вечером 24.08.

## Отчётность

Скрин Ads Manager (разбивка по ad set и ad: показы, CTR, клики, лиды,
CPL) — владельцу агентства каждые 2 дня и итогово 25.08.
