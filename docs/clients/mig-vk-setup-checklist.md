## 0. Блокер: бриф (без него не двигаемся дальше п. 1)

Вопросы Чигрову — в chigrov-vk-projects.md. Минимум для старта:
что за проекты, ближайшая дата очного события, цена/мест, что уже
есть (лендинг, фото, отзывы).

## 1. Настройка сообщества (Тина, ~1 час)

- [ ] Название: имя + суть, например «Александр Чигров | …» —
  формулу утвердить после брифа (личный бренд, не бренд МИГ).
- [ ] Статус/описание: кто он, что за проекты, для кого, «Москва,
  очно» — короткий текст дам на вычитку журналисту после брифа.
- [ ] Кнопка действия: «Написать сообщение» (заявки в сообщения
  сообщества).
- [ ] Меню: ближайшее событие → лендинг/анкета; «Обо мне»; отзывы.
- [ ] Включить «Сообщения сообщества» + приветственное автосообщение
  (напишу после брифа, вычитка журналистом).
- [ ] Подключить сообщество к рекламному кабинету; VK-пиксель на
  лендинг события; проверить регистрацию самозанятого (ИНН) для
  маркировки ОРД/erid — VK Реклама передаёт данные в ЕРИР
  автоматически. Юридически чисто: свои услуги (422-ФЗ).
- [ ] Указать город Москва, контакты.

## 2. Визуал (дизайнер, после брифа)

- [ ] Обложка десктоп 1920×768 + мобильная 1196×600 — живое фото
  Чигрова, не абстракция (личный бренд продают лицом).
- [ ] Аватар — портрет, читаемый в кружке 200×200.
- [ ] 3–5 баннеров меню (единый стиль).
- Стиль: НЕ айдентика «Сложного случая» (она продуктовая) и не
  общебрендовый МИГ — отдельный визуал личного бренда. Вопрос
  общебрендового сообщества МИГ снят вводной 11.08.

## 3. Минимальный контент до рекламы (5–7 постов)

Реклама на пустое сообщество = недоверие. До запуска опубликовать:
пост-знакомство (кто такой Чигров: регалии, опыт — только
проверяемые факты), анонс ближайшего очного события, 2–3 экспертных
поста по теме проектов, отзывы участников (реальные, с согласия).
Если у Чигрова есть контент в других соцсетях — перепаковать оттуда.

## 4. Что НЕ делаем на старте

- Не гонимся за подписчиками сообщества (дорого и не нужно для
  перформанса) — реклама ведёт на лендинг/анкету события, сообщество
  работает витриной доверия.
- Не запускаем рекламу до пунктов 0–3.
- **Не рекламируем через этот кабинет ППК и другие продукты МИГ** —
  реклама чужого (черногорского) продукта от самозанятого =
  запрещённая агентская схема (422-ФЗ). Только авторские проекты
  самого Чигрова.
