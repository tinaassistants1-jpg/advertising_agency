# ППК: план рекламы и ребрендинга (продукт №1)

Статус: **приоритет №1** (решение владельца 06.08.2026). Зеркало плана —
в Notion: блок «📣 Реклама — Nova Leads × МИГ» → «🚀 ППК: план рекламы
и ребрендинга». Экономика — по R04; факты продукта — из каталога МИГ.

## Продукт и экономика

- Форматы: Слушатель / Участник / Практик / Профессионал (каталог).
- Цена: модуль ~250 €; уровень «Практик» ~3 300 € (счёт в каталоге).
- Аудитория: практикующие психологи (РФ, эмиграция, выпускники базовых
  курсов); расходы на развитие 10–30% дохода — покупка из существующей
  статьи бюджета.
- Допустимый CAC: 650–1 350 € (R04); цель теста — CAC ≤ 650 €.
- Прогноз теста: CPL ~20–25 € → 16–25 регистраций на ДОД с 400–500 € →
  доходимость 40–60% → 1–3 покупателя. Одна продажа «Практика» окупает
  тест втрое. Прогноз проверяется тестом.

## Воркстримы (ТЗ + команда + бюджет)

1. **Ребрендинг/переупаковка ППК** — позиционирование «программа
   профессионального роста по стандарту EAGT» (без обещаний защищённых
   титулов ЕС), проверка нейминга уровней, визуальный пакет в бренд-стиле
   МИГ (Druk Text Wide Cyr + Jost), оффер-лестница «модуль 250 € → уровень».
   Команда: Claude (стратегия/тексты), дизайнер (фриланс/Canva),
   представитель МИГ (согласование). Бюджет: 0–400 €. Срок: 3–5 дней.
2. **Лендинг** — черновик готов (`landing-ppk/index.html`); доработать
   тексты/цены, Pixel, вебхук → Google Sheets + email. Домен: рекомендован
   поддомен ppk.mig.institute. Команда: Claude, админ домена МИГ,
   таргетолог. Бюджет: 0–10 €. Срок: 1–2 дня после согласования.
3. **Кампании Meta** — кабинет клиента. Кампания А «ДОД 25.08»
   (до 24.08): Германия+Израиль и Балканы, язык русский, интересы
   психология/психотерапия; 3–4 креатива на аудиторию; ~250 €.
   Кампания Б «ППК напрямую» (26.08–01.10): те же + ретаргетинг; ~375 €.
   Резерв 200 € — в лучшую связку. Команда: таргетолог (или владелец по
   инструкции Claude), копирайтер (Claude), дизайнер. Запуск А: до 12.08.
4. **Аналитика и приём лидов** — Pixel (PageView, Lead), вебхук →
   Google Sheets (+уведомления на admin@mig.institute), регламент МИГ:
   ответ на заявку в течение часа (×7 к квалификации — HBR), еженедельный
   отчёт CPL/доходимость/продажи. Команда: Claude + менеджер МИГ. 0 €.
5. **Тесты** — офферы (ДОД vs программа напрямую), креативы
   (лицо-преподаватель vs выгода-EAGT vs боль-сложные случаи), гео
   (DE+IL vs Балканы). Критерии успеха: CPL ≤ 25 €, доходимость ≥ 40%,
   ≥1 продажа уровня или ≥3 модулей за 6 недель, CAC ≤ 650 €.

## Пошаговая инструкция запуска

1. [МИГ] Подтвердить цены/тексты (1 день).
2. [МИГ] DNS ppk.mig.institute; доступ к Facebook BM + Pixel ID (1 день).
3. [Claude] Финализировать лендинг: тексты, пиксель, вебхук (1 день).
4. [Claude+дизайнер] 6–8 креативов + тексты объявлений → согласование (2 дня).
5. [Таргетолог/владелец] Сборка кампании А, модерация, запуск до 12.08.
6. [МИГ] Регламент обработки лидов: ответ ≤ 1 часа, скрипт приглашения на ДОД.
7. [Claude] Мониторинг ежедневно первые 3 дня, отключение слабых креативов;
   отчёт после ДОД 25.08.
8. Запуск кампании Б (26.08) с учётом данных А; финальный отчёт ~05.10
   с решением о масштабировании (mig-scaling.md).
