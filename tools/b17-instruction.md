# Как запустить парсер b17 — пошагово

Парсер собирает из каталога b17.ru профили психологов: имя, город,
подход, стаж, цены, открытые контакты (email/телефон/соцсети — только
то, что человек сам опубликовал), текст «о себе». Результат — файл
Excel (CSV), открывается в Экселе и Google Таблицах.

## Шаг 1. Установить Python (один раз)

- **Windows:** зайти на python.org → Downloads → скачать, при установке
  ОБЯЗАТЕЛЬНО поставить галочку «Add Python to PATH».
- **Mac:** Python обычно уже стоит. Проверить: открыть «Терминал»,
  набрать `python3 --version` — если показал версию, всё есть.

## Шаг 2. Установить 3 библиотеки (один раз)

Открыть командную строку (Windows: «cmd»; Mac: «Терминал») и вставить:

    pip install requests beautifulsoup4 lxml

(на Mac, если ругается — `pip3 install requests beautifulsoup4 lxml`)

## Шаг 3. Положить файл парсера

Скачать `b17_parser.py` (я пришлю) в любую папку, например на Рабочий стол.

## Шаг 4. Указать, ЧТО собирать

Открыть `b17_parser.py` в Блокноте (Windows) или TextEdit (Mac).
В самом верху, в блоке НАСТРОЙКИ, найти `START_URLS` и вписать адреса
каталогов. Как взять адрес: открыть b17.ru, выбрать город/фильтр,
скопировать ссылку из адресной строки браузера. Пример уже вписан
(Лимассол) — можно заменить или добавить свои.

Там же можно поменять:
- `MAX_LISTING_PAGES` — сколько страниц каталога листать (начни с 2–3);
- `MAX_PROFILES` — сколько профилей всего собрать (для теста 60).

Сохранить файл.

## Шаг 5. Запустить

В командной строке перейти в папку с файлом и запустить. Например,
если файл на Рабочем столе:

- **Windows:** `cd Desktop` затем `python b17_parser.py`
- **Mac:** `cd Desktop` затем `python3 b17_parser.py`

Скрипт будет показывать, что делает. Рядом появится файл
`b17_results.csv` — это результат. Открыть двойным кликом (Excel)
или загрузить в Google Таблицы.

## Если что-то пошло не так

- «python не является командой» (Windows) → Python поставлен без галочки
  PATH, переустановить с галочкой.
- Пусто в результате / «Ничего не найдено» → открой ссылку из
  START_URLS в браузере: она рабочая? Не просит ли капчу?
- Профили собираются, но контактов мало → это нормально: многие
  психологи не публикуют контакты в открытом профиле, скрипт берёт
  только опубликованное.
- Скрипт «завис» → он специально ждёт 3–6 секунд между профилями
  (защита от блокировки). Это нормально, не закрывай.
- Прервалось на середине → просто запусти снова: уже собранные
  профили пропустятся, продолжит с того же места.

## Важно про закон (коротко)

Скрипт берёт только открытые данные. Собранные контакты — для
ТОЧЕЧНОЙ переписки/опроса по одному, не для массовой рассылки
(в РФ это ст. 18 ФЗ «О рекламе», в ЕС — GDPR). Подробные правила —
лист «Правила» в таблице platforms-db.xlsx. Пауза между запросами
(3–6 сек) стоит намеренно — не убирай, иначе сайт заблокирует.
